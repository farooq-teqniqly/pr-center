# PR-Center

A single-user "review inbox" for GitHub pull requests. PR-Center is a self-hosted
web app, run via xcopy install, that consolidates every PR awaiting your review —
across multiple orgs and your personal account — into one list, and layers a
read-vs-unread model on top of it.

**[Download v1.0.0](https://github.com/farooq-teqniqly/pr-center/releases/tag/v1.0.0)**
(Windows/macOS, self-contained, no install required).

  screenshots and install instructions.
- **Contributing or building from source?** See the [Developer Guide](DEVELOPER.md)
